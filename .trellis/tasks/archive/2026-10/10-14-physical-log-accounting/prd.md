# 本地物理日志计量与诊断核对

## 目标
承担父任务 AP01/AP02（T01–T08、R11）。计入本地可核验的历史原生消耗，避免稳定 Session ID 下仅选最长文件造成遗漏；依据真实不确定性分级诊断。

## 范围与验收
- 原生同 owner/response 只计一次；同 Session 的不同物理代独立响应保留，真实继承外来 owner 不混入。样例能复现父研究发现的遗漏；禁止直接相加旧累计流。
- 重复 response 用量、模型、Turn 或 owner 冲突明确提示；记录内部 ID 不发生位置碰撞。会话、模型、日期/小时和列表合计一致。
- 校验本地 history_base 引用，存在且有效不称缺失；缺失/越界/循环/截断明确说明覆盖不足。空计量流不能作为严格继承证明。
- 信息/警告/错误为 typed diagnostics，保留来源与受影响会话，不能从字符串推测类型。真实漏计及损坏不静音。
- 自动覆盖相同副本、非空严格前缀、同总量不同响应、同响应冲突、物理后续段、缺失模型、子会话、压缩、旧累计、损坏、部分写入和跨天。

## 边界与顺序
第一执行项；不依赖另两子项。按父最终方案一次批准；当前 planning。不恢复对话文本、不访问外部引用、不猜测不可核验支出。取舍与口径见父 design.md，研究是 metadata-only；真实日志不写入测试或交付包。
