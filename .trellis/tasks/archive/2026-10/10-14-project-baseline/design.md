# Project Baseline Design

The persistent product baseline lives in `docs/requirements.md` and `docs/design.md`, not in ephemeral conversation history. README links to them; VERIFICATION.md remains the source of executed checks.

This parent owns the documentation baseline and integration review. Child `10-14-token-display-units` owns the R12 UI implementation. The bootstrap-guidelines task remains separate and is not declared completed.

Each subsequent task references product requirement IDs, preserves actual-versus-planned status, and updates design when contracts change. No new application architecture, model pricing or date picker is introduced here.

The root is not a Git repository. Task artifacts and files are persisted locally; no commit, branch, or remote submission can be claimed.
