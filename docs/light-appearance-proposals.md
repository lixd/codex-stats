# 浅色视觉方向比较

2026-10-15；状态：**已选择 D 布局和 D/A 配色，原型本身不进入产品**。原型探索时产品基线为v0.2.12/build14；选定方案现已进入v0.2.13/build15，具体原生实施契约见 [D 原生布局与双配色](native-cyan-blue-design.md)。

用户认为 Sage + Teal 仍不够好看，要求更浅、更简洁、清新，先预览再改产品代码。关联 R04–R08 / R11 / R12 / R17；计量契约 T01–T11 不变。

## 预览入口

[独立 HTML 原型](prototypes/light-appearance/index.html) 完全自包含，不需要安装任何依赖；可直接用浏览器打开。若需要本地 URL，从仓库根运行：

```bash
python3 -m http.server 8753 --bind 127.0.0.1 --directory docs/prototypes/light-appearance
```

浏览器访问 `http://127.0.0.1:8753/?variant=A&page=overview`。底部可选 A/B/C/D，左右方向键循环；在输入框中方向键不切换方案。左侧导航切换总览、请求、模型、会话。查询参数 `variant=A|B|C|D` 与 `page=overview|requests|models|sessions` 保留当前方向和页面。

## 四个方向

| 方向 | 视觉与结构 | 适用偏好与取舍 |
|---|---|---|
| A 晴蓝 | 冷白、淡蓝灰侧栏、柔和蓝强调；四个指标合为连续条，趋势单独分组，模型和明细并排 | 清爽、熟悉、信息容易扫读；仍有少量卡片 |
| B 纸白 | 暖纸白、少量杏棕；总量更突出，趋势与明细主要由细线和留白分隔 | 更平、更克制，卡片感最低；不如蓝紫方向有清凉感 |
| C 雾紫 | 近白紫灰、淡紫强调；总量与趋势构成主区域，输入/输出/缓存排列在右侧 | 层级更柔和、主体集中；较窄窗口需要另行设计响应方式 |
| D 浅青 | 近白青底、白色内容面、柔和青色图表；沿用 A 的连续指标条以比较蓝/青色调 | 更清新、轻盈；避免大面积深青绿，正文仍用深灰 |

|---|---|---|---|---|

| 选中底 | #E6EDF9 | #EEE5D8 | #E9E4F5 | #DFF0F2 |

以上是本项目的设计提案，不声称外部设计系统推荐了整套方案。四套都保留离线/只读属性、四档时间范围、风险提示、模型未知与未完整记录；没有增加图标装饰、价格、订阅额度或线上功能。

## 证据边界与下一步

预览采用相同合成数值和 macOS 系统字体，分析窗口框为 1120×760 CSS px。HTML 用于快速比较，**不是 SwiftUI 原生渲染**，也没有读取真实日志或接入 App。仅方案切换、页面导航和本地文字搜索可操作；时间控件、刷新、排序、复制和详情按钮为示意。菜单、请求 inspector、深色、极端名称、VoiceOver 和全部真实交互尚未设计/验收。

选择方向后，先更新 requirements 和受影响 UI 设计，明确原生组件、实际点尺寸、窄窗口、菜单、深浅色、风险与空态；经用户确认范围再实施。不会把原型 HTML 带入产品，不引入第三方运行时。

本轮记录见 [Trellis 任务](../.trellis/tasks/archive/2026-10/10-15-light-appearance-preview/prd.md)；渲染与检查证据见 [preview-evidence](../.trellis/tasks/archive/2026-10/10-15-light-appearance-preview/preview-evidence.md)。
