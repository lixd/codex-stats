文档更新：2026-10-15；实现基线日期：2026-10-14。对应版本 v0.2.9 / build 11；发布与验证状态以 VERIFICATION.md 为准。

本文件记录产品需求和当前实现状态；技术方案见 [设计文档](design.md)，执行证据见 [验证记录](../VERIFICATION.md)，安装说明见 [README](../README.md)。状态「已实现」不等于真实交互已验收。

## 产品目标与边界

面向使用官方 Codex 订阅的 macOS 用户，提供轻量、原生、可独立安装的本地 Token 分析工具。产品名为 **Codex Stats**，最初的 Codex Pulse 名称已替换。优先级：统计准确性 > 可运行与安装 > UI 品质 > 性能优化 > 其他扩展。

仅分析本地日志，不解释订阅额度或实际扣费。目标平台 macOS 14+，采用 SwiftUI，必要时使用 AppKit，零第三方运行时依赖。

明确排除：账户登录、OAuth/API Key、订阅剩余额度、多 Provider、API 中转、模型切换、在线模型调用、云同步、用户系统、复杂插件和 Electron。

## 统计契约

| ID | 必须满足的规则 |
|---|---|
| T01 | Total = Input + Output；Cached 已含在 Input，Reasoning 已含在 Output，不能重复求和 |
| T02 | 模型来源必须可核验；无法归属时为 `Unknown model`，不使用未来上下文回填，不猜别名 |
| T03 | 累计快照不能直接相加；处理重复、重置、缺失基线和最近一次用量重发 |
| T04 | 独立请求按真实 response_id 去重；处理继承历史、活动 / 归档副本及压缩，不能交叉差分两种累计口径 |
| T05 | 每个可计入事件按本地事件时间归属；跨日期 / 模型无法拆分的部分不猜测补齐 |
| T06 | 缺少缓存或推理字段必须标注「未完整记录」；无真实身份显示「未记录」，内部归组名称不当作真实 ID |
| T07 | 已计入逐条记录的合计必须与同一范围下会话、模型和总量一致；累计增量可能包含多次请求，记录条数不能当作真实请求数 |
| T08 | 损坏、部分写入、非法值、缺失时间与溢出有可观察提示；不能伪造消耗或成功状态 |
| T09 | 全部物理历史中真实 owner / response_id 证明的已发生消耗保留；矛盾身份排除并诊断，无身份累计流不盲目合并 |
| T10 | Turn 耗时 / TTFT 仅来自合法完整生命周期；平均输出使用全 Turn 去重输出，不随日期 / 模型 / 搜索截断；覆盖不完整不计算均速 |
| T11 | 请求估算与 Turn 计时独立；须匹配真实 owner / response / Turn 与有效事件边界。缺少、冲突、中止、损坏、压缩和累计记录不填充估算；估算不改变 Token 计量 |

具体算法及保守处理见设计文档；这些数据只代表本机保留日志，不能恢复其他设备、云端或已删除历史。

T04 的当前入口比较显式 thread_id 与内部log.id，缺元数据时log.id为文件名；两者恰好相等可能被接受，尚未完全满足要求真实Session ID的目标。见 [数据设计](data-design.md)，后续需先设计、再修复与回归验证。

T06 的真实身份区分已在请求明细/CLI实现；会话页目前直接展示并复制本地归组ID，缺少原始Session ID时尚未单独标记，属已知缺口，见 [当前UI设计](ui-design.md)。不得把该展示行为当作真实身份存在的证据。

## 隐私与数据范围

- 默认读取 `~/.codex/sessions/**/*.jsonl` 和 `~/.codex/archived_sessions/**/*.jsonl`；支持 CODEX_HOME、显式日志目录及多个目录。
- 不读取 auth.json、账户凭证、API Key 或模型配置，不请求网络。
- 不保存提示词或响应正文；缓存仅保留计量和必要身份 / 时间 / 目录元数据。
- 真实日志不进入源码包或测试数据；自动化 fixture 使用合成数据。

## 非阻塞与延期项

API 等值成本是可选后续需求，**尚未实现**。若未来实现，必须使用已确认价格、未知价格不估算，并明确不是订阅实际费用。缓存写入、状态码和实测单请求耗时 / 生成速度缺少可靠数据，不能用零填充。v0.2.7 请求性能提供明确标记的事件边界估算；完整 Turn 实录性能另有独立范围。
