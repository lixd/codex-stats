# 安装与使用

所有命令均在仓库根目录执行。返回 [项目首页](../README.md)；需要核对统计口径时见 [统计说明](statistics.md)。

## 安装与运行

已有构建产物时，将 `dist/CodexStats.dmg` 中的 **Codex Stats.app** 拖入 Applications，或直接打开 `dist/Codex Stats.app`。启动后从顶部菜单栏的波形图标打开总览，再点击「打开完整分析」。关闭分析窗口不会退出菜单栏应用；点击菜单栏弹窗底部的「退出」或分析窗口左下角的「退出应用」，或在应用获得焦点时按 ⌘Q，可结束整个应用。重复打开同一 bundle identifier 的副本时，新实例退出并激活先前运行的实例；更新前仍需退出旧版本。

开发构建使用本机 ad-hoc 签名，尚未使用 Developer ID 签名或 Apple 公证。分发给其他 Mac 时可能被 Gatekeeper 拦截。本次二进制为 Apple Silicon；Intel Mac 请在本机从源码构建。本次在 macOS 27.0.1 上构建和启动，macOS 14 最低系统尚未实机验证。

从源码安装（需要 Xcode 或 Apple Command Line Tools）：

```bash
./Scripts/install-local.sh
```

安装位置为 `~/Applications/Codex Stats.app`。更新前请先从菜单栏退出旧版本；脚本发现同一 App 仍在运行会拒绝替换，不会自动结束进程。新版本先在同卷暂存并校验，再原子替换旧版本；编译、复制或校验失败不会删除旧副本。只有确认指定路径和版本的新进程完成启动后才报告启动成功。若提示“已替换，但启动未确认”，目标文件已经更新，旧副本仍保留在提示的路径；检查错误原因后再手动处理，不要把该提示当成安装完全失败而忽略已更新的目标。

已有构建产物可用 `./Scripts/install-local.sh --source "/path/to/Codex Stats.app"` 安全安装；隔离验证可额外指定 `--destination "/temporary/path/Codex Stats.app"`。直接拖拽 DMG 中的 App 不经过脚本的这些保护，仍应先退出旧版本。

进程生命周期检查（macOS，先退出所有已运行副本）：`./Scripts/test-app-lifecycle.sh`。该检查实际启动 App、强制再次打开副本、确认只保留原实例，再通过 AppKit 正常退出；不代替退出按钮的点击验收。

只构建、试运行或生成 DMG：

```bash
./Scripts/build-macos.sh
open "dist/Codex Stats.app"
./Scripts/make-dmg.sh
```

若没有编译工具，运行 `xcode-select --install`。App 打包脚本直接使用系统 Swift 编译器；Swift Package、测试和核对 CLI 需要 **Swift 6.0+**。Shell 中的 `swift` 可能是同名 Python 命令，macOS 下使用 `xcrun swift`。

## 功能

- 菜单栏：今天、近 7 天、近 30 天、全部；输入、输出、缓存输入、推理、总量，前两个模型和最近成功刷新时间。
- Overview：紧凑 Token 指标、趋势、模型排行和按级别分组的数据质量提示；精确数字可查。
- Requests（请求日志）：按时间、总 Token 或模型排序；按模型筛选，搜索项目、模型、Session ID、请求 ID 或 Turn ID；选择记录在原生独立面板打开详情，复制已有 ID，并展开原始用量与累计快照。关闭面板保留查询和排序；宽窗口十列、窄窗口相关字段双行组合为七列，保留全部信息且无需横向滚动，记录列表正常纵向滚动。
- Sessions：按项目、Session ID、模型搜索，按最近活动、总量或项目排序；会话详情显示 Token 缩写及会话内各模型明细，悬停可查看精确数字。全部时间包含没有 Token 记录的会话。
- 手动刷新；顶部和设置中可选择自动刷新，间隔可选 30 秒（默认）、1 分钟、5 分钟、15 分钟，并可关闭自动刷新。间隔选择会保存，切换后立即重新计时；升级时未选择过间隔的自动刷新用户使用 30 秒，原先关闭自动刷新的用户仍保持手动刷新。刷新时间精确到秒，只记录成功扫描。日志路径出错时仍可打开分析窗口进入设置。

设置中的“配色”可选择默认浅青或晴蓝，两者共用D布局，明暗跟随系统，选择会保存。切换只改颜色，不重新扫描日志。

总览采用四张独立指标卡与全宽柱状图：今天按本地小时汇总，其他范围按日汇总；下方提供模型排行与完整 Token 明细。小时趋势使用与总量相同的已去重增量，不重新累加原始快照。当天没有已计入事件的小时以零显示，不代表能恢复缺失日志；遇到夏令时，按实际的 23 或 25 个小时显示。

Token 显示统一使用国际单位：百万以上使用 M（十亿以上也保留 M），万以上不足百万使用 K，较小数字显示原值；M 最多两位小数、K 最多一位，去掉多余尾零。临近百万的舍入边界会显示 1M，避免 1000K。趋势图不使用科学计数法或「万 / 亿」。总览及会话、请求的 Token 明细缩写可悬停查看精确值；菜单底注、指标卡副标题、会话和列表合计也使用共享 K/M；精确数字可通过悬停和原始计量详情核对，CLI 仍输出整数。缺失字段继续显示「未完整记录」。

可运行 `./Scripts/render-ui-previews.sh` 在 `dist/ui-previews` 生成原生 SwiftUI 总览、菜单、请求列表（950 / 1120 宽度）、请求详情面板及加载 / 空 / 错误状态的深浅色 PNG。预览仅使用脚本生成的合成日志，不读取真实 Codex 会话、不更改系统主题；这些图片验证页面渲染，不验证真实菜单栏点击。

请求日志显示的是**已纳入统计的用量记录**，不是所有成功或失败的网络请求清单。独立请求来自真实 `response_id`；旧日志的最近一次用量、累计增量、初始快照会分别标注，累计记录可能包含多次请求，不能当作一次请求或直接计数。零用量、已去重、无法计量的事件不进入该列表。记录之和与同一范围的汇总一致；加上搜索或模型筛选后，底部合计仅包含当前列表。

缺少真实 Session ID、response_id 或 Turn ID 时显示「未记录」，内部行标识或文件名不充当真实 ID；缺少缓存/推理字段时显示「未完整记录」。详情区展示已计入的六项 Token 数字，并明确区别独立请求的 `thread_token_usage` 与旧格式的 `total_token_usage`。v0.2.16在已计入用量后显示缓存率与API等值估算，价格说明在设置中；原始快照不另估金额，没有缓存写入或状态码。单请求耗时没有实测日志字段；v0.2.7 根据可匹配到真实 response_id / Turn 的日志事件边界估算，耗时及输出速度均标注 **≈**。开始取首个模型输出之前的用户 / 上下文 / 工具结果边界，结束取原生 usage 记录时间，包含首次 Token 等待及可能的重试。缺少或矛盾边界、压缩、累计与初始快照仍显示 —；估算耗时须在 100 ms 至 1 小时之间，输出至少 200 tokens 且耗时至少 1 秒才显示 tok/s。不能把它当作实测生成速度，也不使用单个 item 包络或无边界的相邻请求时间差。详情另列可核验的完整 Turn 耗时 / TTFT；覆盖确认后才计算全 Turn 去重输出 / 耗时的平均 tok/s。这个指标包含工具与等待，不能解释为纯生成速度；其分子不受日期、模型或搜索筛选截断。缺失、失败、中止或矛盾的生命周期不产生假性能。

菜单栏弹窗采用紧凑布局；点击“打开完整分析”或统计提示，会先关闭菜单自身的弹窗，再显示分析窗口。关闭分析窗口后菜单栏进程继续运行；仅明确退出或 ⌘Q 结束应用。应用主动禁用空闲自动终止，不阻止系统睡眠，也不保证抵御崩溃或系统强制终止。请将 App 拖入 Applications 后运行，避免长期从挂载 DMG 启动。

菜单栏与分析窗口共享时间筛选。7 天包含今天及之前 6 个本地日历日；30 天同理。日趋势最多显示最近 30 个有记录的日期，不推算缺失日志的消耗。

## 数据来源与隐私

默认仅扫描：

```text
~/.codex/sessions/**/*.jsonl
~/.codex/archived_sessions/**/*.jsonl
```

首次启动可继承 `CODEX_HOME`；Finder 启动不一定继承 Shell 环境。设置中可指定 Codex home，也可显式选择单独的 JSONL 文件夹。多个路径用英文逗号分隔。

应用不读取 `auth.json`、账户凭证、API Key、模型配置或数据库；不调用账户接口，不上传日志，不保存提示词或响应正文，不跟随 JSONL 符号链接。扫描过程中 JSON 对象短暂存在于内存，仅 Token、模型、目录、会话身份和时间元数据进入缓存。UserDefaults 仅保存目录与自动刷新偏好。

解析器在后台 actor 串行执行，不阻塞 UI 主线程。文件按大小与修改时间缓存；未变更文件不重读，变更文件以 64 KiB 分块重新解析；每次读取和每行 JSON 解析分别使用自动释放池，及时释放 Foundation 临时对象，避免扫描中积压。首次读取显示加载状态，后续刷新保留成功数据，失败保留成功时间并显示错误。日期解析复用不可变格式，筛选每次只计算一次本地日期边界。当前是文件级缓存，尚未实现字节级追加解析、文件监听或持久缓存。界面复用单个当前范围摘要，减少重复聚合；系统时区变化后请重启，以重新建立日期桶。

## 已知限制

- Codex 日志不是稳定的计费协议；更新 CLI 后应复测。已删除的历史、分页中缺失的部分、其他设备/云端未保留日志无法补齐。
- 未验证的旧 fork/重写历史可能偏高；保守去重、字段缺失、损坏日志和缺失基线也可能少计。界面警告是结果的一部分。
- 无真实身份的旧累计流无法证明不重叠时不会合并，可能少计；原生请求的真实身份冲突会排除该身份并明确提示。
- 文件级缓存仍需枚举目录；增长中的大文件会重新解析。系统时区改变后请重启应用重新分桶。
- 本次完成原生编译、签名检查和进程启动验证，以及总览、菜单、请求列表和详情的原生深浅色静态渲染检查；UI 自动化服务超时，真实菜单点击、页面交互及其他页面的视觉验收仍待人工完成。
- 没有 Developer ID、公证、Intel 二进制或 macOS 14 实机验证；提供源码供目标 Mac 本机构建。

## 查看缓存率和美元参考金额

菜单、总览及会话/请求详情显示同范围缓存率与API等值估算；请求列表保持Token列和原排序。金额表示官方API标准参考价折算的用量价值，不能当作订阅扣费或剩余额度。“已估算小计”只涵盖可估部分，下方会列未估Token及原因；“无法估算”不是零消耗。缓存字段缺失显示未完整记录，零输入比例显示—。

金额精确值、覆盖与定价口径在help中可查，设置中可查看价表版本/日期/不含项并进入“管理模型价格”；App不联网同步价格。详见[统计说明](statistics.md)和[指标设计](cache-rate-cost-design.md)。本地v0.2.21 App构建见[验证记录](../VERIFICATION.md)，不自动安装到正在使用的版本。源码由Git管理，默认不另打源码包。


## 管理模型价格

在设置中打开“管理模型价格”。添加时从原生下拉选择模型：候选为当前日志目录全部历史中有已接受用量、且尚未配置价格的精确模型；无需重新扫描，也不限制为最近7天。未知模型身份不能手动猜价。

输入、缓存输入、输出单价均为USD/百万Token，三项必填，允许0，小数点使用`.`。编辑后标为自定义，所有历史按当前价表重算参考金额，不改变Token或日期范围。实际账单、长上下文和服务档费用不在此估算内。

内置与自定义价格均可删除，但全部历史还有对应模型记录时不能删除；扫描失败/未完成或有警告时也不能确认安全删除。删除仅移除价表记录，重启不会补回内置价。价格文件为`~/Library/Application Support/Codex Stats/prices.json`，App/CLI共用；读取或保存失败会显示错误，不静默改成默认价。没有文件才使用内置默认表。


## 总览按模型查看

总览顶部模型下拉来自全部历史已接受记录，数字为当前时间范围记录数。“全部模型”固定首项，其余按记录数从多到少、同数按模型ID排列。选择后，API等值估算、Token、缓存率、记录数、趋势及下方明细同步变化；零记录范围保持所选模型。选择只影响总览，不改变Codex实际模型或菜单统计。点击“查看用量记录”会带入所选模型进入现有请求页。

v0.2.18新增gpt-5.6-sol和gpt-6-sol默认价。已经保存过价格表时，在设置→管理模型价格点击“补充新增内置价”，只添加缺失的新行，不覆盖已有自定义价或恢复其他删除项。codex-auto-review保留未计价，可自行配置有依据的参考价。


v0.2.19分析导航精简为总览、请求日志、历史会话、设置。独立模型统计页删除；按模型查看用量请用总览顶部下拉，逐条记录在请求页筛选，价格编辑仍在设置。

总览趋势右上可切换Token／记录数／API等值金额，随当前模型和时间范围变化。记录数不是确认请求数；部分估算和未计价用符号及文字标明，未计价不代表$0。
